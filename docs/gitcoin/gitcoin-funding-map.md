### 5.2 Minimum viable score
- **Default binary threshold = 20** ("Unique Humanity (binary)" scorer; 20 = effective at eliminating Sybils, low risk to real users; 25 = more effective; 30 = most effective). Source: https://docs.passport.xyz/building-with-passport/stamps/major-concepts/scoring-thresholds

- **For Weft's wallet:** clearing 20 with wallet-only stamps is plausible if the wallet has genuine history: e.g., ETH Activity ≥16 (ETHScore#50) + NFTScore ≥16 (already >20 from two stamps alone, before adding Gitcoin history/ENS/Safe). But note: score thresholds like ETHScore#50 require real, aged onchain activity — **do not farm this; model-based and COCM sybil-detection explicitly punish factory wallets.**

### 5.3 Agent identity strategy
- **Primary: Passport Models API** — "classify any EVM address as Sybil or human, without requiring users to have a Passport Stamps account" — ML over ETH L1 + L2 onchain activity. An agent wallet with organic, varied, non-factory behavior can pass as human. This is the agent-accessible identity primitive. Source: https://docs.passport.gitcoin.co/ (Models section)
- **Secondary: wallet-only stamps** (ETH Activity, NFT, Identity Staking, Gitcoin, ENS/Safe/Snapshot).
- **Do NOT** link Kevin's human X/Discord/Google to the agent wallet — it contaminates the "pure agent" narrative that IS Weft's pitch, and creates a sybil-anomaly signature. If a venue requires human stamps, that venue is Kevin-gated by definition (see §6).
- **Caveat (honest):** Gitcoin's ML will see an agent-run wallet as *unusual* even when legitimate. Provability is Weft's counter: publish the wallet's full behavioral trail in the ledger, so any sybil-review finds an open book, not a black box.

## 7. Scam / honeypot flags (and what's legit)

1. **"Processing fees" to receive matching** — RED FLAG, always. Gitcoin/Giveth/Octant/Atlas charge no application fees; donors pay gas. Any venue asking for a fee, credit card, or "refundable deposit" to unlock matching is a scam. (This directly answers the brief's red-flag question.)
2. **Fake "RetroPGF" portals** — the old retrofunding.optimism.io moved to atlas.optimism.io; impersonator sites are circulating in the wild. Official: https://atlas.optimism.io/ · governance: https://gov.optimism.io/
3. **Octant/Giveth clones** — official: octant.app, giveth.io, docs.octant.app. Verify the domain before connecting any wallet.
4. **Passport "premium verification" sellers** — core Passport Stamps are free; "custom Passport" customization is a developer product for integrators, not an applicant upsell (https://docs.passport.xyz/.../custom-passport). Anyone selling score-boosting is a sybil operator.
5. **Deep Funding/Seer "evaluator" recruitment scams** — evaluation markets are real (https://gov.gitcoin.co/.../model-submissions-gg24-deep-funding/25151), but nobody legitimate charges fees to evaluate.
6. **Wallet-connect phishing in Discord** — Gitcoin, Giveth, Octant, Optimism all have real Discords; a DM offering "expedited review" for a small fee is a scam. No expedited review exists.
7. **Legit costs to expect:** only network gas fees (donations/txns) and, for Octant app-mode, GLM staking gas. Yield-funded matching (Octant × Gitcoin) is real but the yield pays *Gitcoin's* matching pool — no venue pays Weft "yield" on its own funds as a grant mechanism.
8. **Diligence note on the Octant vaults** (since Weft may reference them): Octant v2 vaults are non-custodial, Yearn v3 architecture, unleveraged, audited (most recent: Spearbit; audits public in golemfoundation/octant-v2-core). Legit — but always verify the vault address on-chain before interacting. Source: https://gov.gitcoin.co/t/withdrawn-gitcoin-x-octant-yield-powered-matching-for-gg25/24977
